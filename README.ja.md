# sakacchi

地域をきれいにする、ボランティア型カードコレクションゲーム。ゴミを拾って、モンスターカードを集めよう！

## デモ
https://ai-sakai.sabae.cc/

## ゲームプレイ
1.  **🗑️ ゴミの発見と撮影:** アプリのカメラを使って、地域で見つけたゴミを撮影します。
2.  **🤖 AIによる判定:** AIが撮影した画像を分析し、対象がゴミかどうかを判定します。
3.  **🃏 カードの獲得:** ゴミと判定された場合、宝箱からランダムにカードを1枚引くことができます。
4.  **✨ レアカードの解放:** 特定のカードの組み合わせを集めると、「宝箱」ページで4枚の強力なEXカードを解放できます。
5.  **🏆 コレクションの完成:** 全34種類のユニークなカードをすべて集めると、特別な感謝状がもらえます。

## 機能
- **AIによるゴミ判定:** OpenAIのビジョンモデルを使用して、撮影された対象がゴミかどうかを識別します。
- **カードコレクションシステム:** 5段階のレアリティを持つ全34種類のユニークなカードを収集できます。
- **特別な解放条件:** 特定のカードを組み合わせて、レアなEXカードを解放します。
- **ローカルでの進捗保存:** 集めたカードはブラウザの `localStorage` に保存されます。
- **レスポンシブデザイン:** デスクトップとモバイル端末の両方で快適に動作します。

## 技術スタック
- **バックエンド:** [Deno](https://deno.land/)
- **フロントエンド:** HTML, CSS, JavaScript (ES Modules)
- **AI:** OpenAI Vision API（`fetchImageRecog` ライブラリ経由）
- **データ永続化:** ブラウザの `localStorage`
